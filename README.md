# Homebridge Tapo Alarm

An independent Homebridge plugin project based on [Kevin Hillinger's homebridge-tapo-smarthome](https://github.com/kevinhillinger/homebridge-tapo-smarthome).

## Project goals

- Preserve support for Tapo H100 and physical S200 button accessories.
- Report the H100 alarm state to HomeKit without making HomeKit arm/disarm commands start or stop the siren.
- Investigate reliable alarm-state detection and native Apple Home notifications.
- Preserve attribution and upstream license notices.

This repository is an independent derivative project. It is not affiliated with TP-Link.
